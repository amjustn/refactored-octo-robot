## 六关快速筛选

### 第一关：能力圈

*   **能用一句话说清楚公司靠什么赚钱吗？**
    工商银行主要通过吸收企业和个人存款，然后以更高的利率发放贷款给企业和个人，赚取利息差（净息差）。此外，它也通过提供支付结算、财富管理、投资银行等服务赚取手续费和佣金（非利息收入）。

*   **10年后大概率还在做什么生意？**
    10年后，工商银行大概率仍在经营存贷款、支付结算、财富管理等核心银行业务。只要中国经济持续发展，现代商业活动就离不开银行作为信用中介和支付枢纽。银行作为金融体系的“主动脉”，其核心功能不会被轻易替代。它可能更多地转向数字化、智能化服务，但商业模式的本质——吸收存款、发放贷款、管理风险、提供支付——不会改变。

*   **哪些关键变量决定成败？**
    1.  **宏观经济与利率环境：** 经济增速、企业盈利状况直接影响贷款需求和资产质量（坏账率）。利率市场化、货币政策（如LPR调整）直接影响净息差。
    2.  **资产质量（信用风险）：** 不良贷款率、拨备覆盖率是银行的生命线。经济下行周期，企业违约风险上升，坏账是侵蚀利润的最大威胁。
    3.  **监管政策：** 资本充足率要求、系统性重要银行附加要求、金融科技监管等，都会影响银行的业务扩张能力、盈利模式和风险成本。
    4.  **数字化转型能力：** 能否有效利用科技降低运营成本、提升客户体验、获取低成本存款、并有效控制风险，是未来竞争的关键。

**结论：** 从传统ROE、毛利和负债水平看，工商银行**绝非典型的“好生意”**。它是一个高杠杆、低毛利、受监管严格、资本消耗型的周期性行业。其经济特征远不如茅台、可口可乐等轻资产、高ROE、强定价权的公司。

### 第三关：护城河

| 类型 | 检查 |
| :--- | :--- |
| **品牌/定价权** | **中等**。“宇宙行”品牌家喻户晓，尤其在机构客户、大型国企和跨境业务中具有极强的品牌信任度。但在个人零售端，定价权很弱（存款利率受管制，贷款利率市场化竞争激烈）。 |
| **转换成本** | **非常高**。这是工行最深的护城河。企业客户与工行建立复杂的支付结算、现金管理、供应链金融等系统后，迁移成本极高。个人客户更换工资卡、房贷、理财主账户的摩擦成本也很大。 |
| **网络效应** | **强**。网点最多、ATM最多、客户基础最大。客户越多，支付网络价值越大；商户越愿意接入，又吸引更多客户。这种双向正反馈效应显著。 |
| **成本/规模优势** | **极强**。凭借最大的存款基础和网点，工行能以最低的成本吸收存款（活期存款占比高）。其庞大的IT系统投入分摊到每笔交易上的成本极低。这是中小银行无法比拟的。 |
| **技术/专利壁垒** | **一般**。技术并非其核心壁垒。工行在金融科技上投入巨大，但更多是应用层面的领先，而非颠覆性技术专利。真正的壁垒在于其庞大的客户数据、风控模型和监管认可。 |

*   **追加检验：给竞争对手100亿，能否复制这门生意？**
    **不能。** 100亿或许能建一套先进的IT系统，挖一个优秀的管理团队，但绝无可能复制工行以下几项核心资产：
    1.  **几十年来积累的数亿个人客户和数百万企业客户的信任关系。**
    2.  **遍布全国城乡的超过1.5万个物理网点构成的线下网络。**
    3.  **国家信用背书和“系统性重要银行”的地位，使其在危机时能获得流动性支持。**
    4.  **与政府、大型国企、地方平台长期建立起的深度合作关系。**

    **结论：** 工商银行的护城河非常宽阔且坚固，主要由**极高的转换成本、巨大的规模成本优势和强大的网络效应**构成。这是其长期稳定盈利的根本保障。

### 第四关：管理层

*   **诚实度（承诺vs交付）：** 国有大行，管理层变动相对频繁，战略方向主要由国家金融政策决定。整体上，财务报表规范，信息披露透明，分红承诺（每年30%左右）基本兑现。诚信风险较低。
*   **资本配置能力（回购/分红/并购记录）：** 资本配置受严格监管。主要将利润用于补充资本和分红。历史上鲜有大规模并购（除了收购标准银行部分股权）。近年加大了分红比例，但**没有股票回购**，对股东回报的提升有限。
*   **股东利益导向（持股、薪酬）：** 管理层薪酬与业绩挂钩，但远低于私营企业。持股比例极低，激励不足。股东利益并非其首要目标，首要目标是**服务国家战略和防范金融风险**。
*   **所有者心态（创始人 vs 职业经理人）：** 典型的**职业经理人**模式，且是行政任命的官员。缺乏创始人那样的主人翁精神和长期主义视角。决策更偏向稳健、合规和完成政治任务。

**结论：** 管理层合格，但不出色。诚信、稳定，但缺乏股东价值最大化的强烈动机和资本配置灵活性。这是投资国有大行必须接受的一个现实。
