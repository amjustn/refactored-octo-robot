# DDM 锚（反向戈登 / 戈登增长模型敏感性）

> 新增时间：2026-09-11　涉及提交：`app/tools/financial_rigor.py`、`app/harness/tools.py`、`app/harness/prompts.py`、`app/skills/investment-research.md`、`tests/test_reverse_gordon.py`

## 1. 为什么加（它补的是哪块缺口）

8001 原有的估值锚只有倍数类（PE / PB / PS，保险另有 P/EV）。倍数回答的是"相对贵贱"，回答不了类债型资产的核心问题：**每年拿到手的股息，够不够补偿我放弃无风险利率的机会成本**。高股息银行的定价主线恰恰是"股息率对十年国债收益率的利差"，而不是账面净资产贵不贵。

同时，报告里原本只能由模型自由叙述折现类结论（例如"反向 DCF 隐含增长 12%~15%"），**没有工具承接、没有留痕、出口一致性校验也管不到**。本锚把折现假设从"叙述"搬进"工具参数"，所有 r 与 g 都进报告、可核对。

## 2. 模型出处

- Myron J. Gordon (1959), *Dividends, Earnings, and Stock Prices*, Review of Economics and Statistics 41(2): 99–105（doi:10.2307/1927792）—— 常数增长折现模型（戈登增长模型）的定型文献。
- 理论前身：John Burr Williams (1938)《投资价值理论》；Gordon 与 Eli Shapiro (1956) 已提出该形式。
- 学界对该模型的态度不是"弃用"而是"反向使用"：由 `r = D1/P + g` 从市价解出隐含增长率或隐含贴现率。实证文献（如 2021 年用戈登分解 GFC 与疫情两次下跌的研究）发现隐含增长率变动的解释力约为贴现率的 1.6~1.7 倍。

## 3. 公式与口径（硬性）

```
正向:  P = D1 / (r - g)          # 给定 r、g 求价格
反向:  g_implied = r - D1 / P    # 给定市价与分红，解市场隐含的分红增长率
```

- `dps`（D1）= **预期未来 12 个月的每股分红**，不是已派发历史、不是单次特别股息；报告中必须写明来源（年报分红方案 / 公司公告）。
- `discount_rates`：三档，须写明构造依据（无风险利率 + 风险溢价）；无风险利率用最新 10 年期国债收益率。
- `price`：当前市价，须来自行情源。

## 4. 接口

路径一（推荐，模型走这条）：`three_scenario(anchor="DDM", dps=..., discount_rates=[...], risk_free_rate=..., shares_100m=...)`

路径二（函数直调）：`app.tools.financial_rigor.reverse_gordon(price, dividend_per_share, discount_rates, risk_free_rate=None, growth_grid=None, shares_100m=None)`

- `growth_grid` 省略时默认 = **中档贴现率下的隐含增长率 ± 1 个百分点**（三点），因此中档行×中档列那一格必然复现当前市价（内置自洽校验）。
- 输出：`implied`（每档 r 的隐含分红增长率、风险补偿、股息率对国债利差）+ `sensitivity`（r × g 的目标价/上涨空间矩阵）+ `warnings` + 假设回显（`discount_rates_pct` / `growth_grid_pct` / `model`）。

## 5. 铁律与拒绝条件（不是报错，是设计行为）

| 条件 | 行为 |
|---|---|
| `dps <= 0`（不分红 / 象征性分红） | 直接拒绝并提示改用 PE/PB/股息率锚 |
| `price <= 0`、`discount_rates` 为空或含 ≤0 | 直接拒绝 |
| 某格 `g >= r` | 该格标记 `model_failed`、**不给目标价**（模型发散趋于无穷） |
| 全部格 `g >= r` | 整体拒绝 |
| 股息率 > 12% | 警告：核实是否含特别股息或口径有误 |
| 反解出负的隐含增长率 | 警告：市场已 price-in 分红下降，需与分红政策对照 |

**不适用清单**：不分红/象征性分红、分红政策不稳定、分红随盈利大幅波动的周期股、高增长期企业（g 逼近 r）。这些标的禁用折现类模型，必须写明弃用理由。

## 6. 报告侧纪律（已写入提示词）

- 必须整表呈现"隐含增长率 + 敏感性矩阵"，并写明 dps 口径与来源、discount_rates 构造依据。
- **禁止把矩阵中的任何单一格当作目标价**，禁止只给一个隐含增长率而不给区间。
- 触发拒绝时应改用 PE/PB/股息率锚并在报告中说明。

## 8. 真实数据实例（招商银行 600036，2026-09-11）

输入（全部实测，未手填）：现价 41.35 元（新浪，经 8000 仪表盘实时接口）；无风险利率 1.682%（英为财情 2026-09-04 收盘；聚金数据 09-10 报 1.679%，两源一致，另有第三源报 1.88% 为离群，未采用）；三档贴现率 = 无风险利率 + 4/5/6 个百分点。

口径A：最近 12 个月实际派发 dps = 3.013 元（2025 中期 1.013 元 + 2024 年度 2.000 元，官方投资者关系页）

- 股息率 7.29%，对国债利差 5.61 个百分点
- 隐含分红增长率：r=5.68% → -1.61%；r=6.68% → -0.61%；r=7.68% → +0.39%
- 敏感性矩阵（元）：r=5.68% 行 41.35 / 47.93 / 56.99；r=6.68% 行 36.36 / 41.35 / 47.93；r=7.68% 行 32.44 / 36.36 / 41.35
- 警告：反解出现负的隐含增长率 → 按常用贴现率，现价已 price-in 分红不增长甚至下降

口径B：仅最近年度分红 dps = 2.000 元

- 股息率 4.84%，对国债利差 3.16 个百分点
- 隐含分红增长率：0.84% / 1.84% / 2.84%
- 敏感性矩阵（元）：r=5.68% 行 41.35 / 52.13 / 70.50；r=6.68% 行 34.27 / 41.35 / 52.13；r=7.68% 行 29.25 / 34.27 / 41.35

结论示例（这一步是模型/人的判断，不是工具输出）：同一现价下，口径A 意味着市场假设分红零增长，口径B 意味着假设年增 1.8% 左右——**口径差异带来的估值差远大于模型精度带来的差异**，所以 dps 口径披露是硬要求。

### 8.1 dps 口径分歧（E2E 实测发现，重要）

上述端到端分析过程中，模型交叉验证出**三套并存口径**，并主动标注为"所有估值结论的核心不确定性来源"：

| 口径 | 数值 | 来源 |
|---|---|---|
| 普通股口径（最纯） | 2.016 元/股（中期 1.013 + 末期 1.003） | 招商银行 2025 年度利润分配方案公告（2026-03-28） |
| 应付普通股股利 ÷ 总股本 | 3.013 元/股（759.88 亿 ÷ 252.2 亿股） | 2025 年年度报告 |
| 预期未来 12 个月 D1 | 2.10 ~ 3.05 元（各分析师取值不一） | 各券商口径 |

含义：**本文件 §8 实例里的口径A（3.013）很可能含优先股股息与永续债利息，不是纯普通股的每股分红**；纯普通股口径应为 2.016 元/股。两种口径对应股息率 4.88% 与 7.29%，进而把隐含增长率、目标价区间整体推移 —— 这正是"dps 必须标注来源与口径、且不得由模型推算"这条硬要求存在的理由。

## 9. 已知数据源缺口（待补，不许静默）
