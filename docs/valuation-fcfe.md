> 新增时间：2026-09-13　提交：`8c13adc`（A 步 D&A 取数）、`4815a77`（B 步 反向 FCFE 锚）
> 涉及文件：`app/tools/financial_rigor.py`、`app/tools/fcfe_inputs.py`、`app/tools/cash_flow_items.py`、`app/harness/tools.py`、`app/tools/valuation_guard.py`、`app/skills/investment-research.md`、`tests/test_reverse_fcfe.py`、`scripts/verify_fcfe_inputs.py`、`scripts/verify_cash_flow_items.py`

## 1. 为什么加（它补的是哪块缺口）

DDM 锚（2026-09-11 上线）解决的是"高股息稳定分红标的"的定价主线，但它的分子是**每股分红**。
对低分红/不分红的公司，这个分子接近 0 → 反解出的隐含增长率被顶到折现率附近（澜起科技股息率约 0.2%，
r=10% 时 DDM 反解 g≈9.8%，几乎没有信息量）。

FCFE 把分子换成**股东能拿到的现金流**：净利润 + 折旧摊销 − 资本开支 − 营运资本增加 + 净借款。
同样不看分红，但看企业真实创造并归属于股东的钱，覆盖"留存但不分派"的公司。

两个锚的分工（写进技能规则，避免误用）：

| 标的特征 | 主锚 |
|---|---|
| 高股息 + 分红稳定（银行/水电/高速/运营商/高派息白酒） | DDM（反向戈登） |
| 低分红/不分红但股东自由现金流为正（科技成长/无派息制造医药） | FCFE |
| FCFE ≤ 0（扩产期/周期底）或取数失败 | 弃用折现锚，改 PB/PE/PS |

## 2. 模型出处

- 教科书来源：Aswath Damodaran《Investment Valuation》第 14 章（FCFE 与 FCFF 的区分、non-cash working capital 口径）。
- 原始思想可追到 John Burr Williams (1938) 的股利折现框架 —— FCFE 是它的"现金流版"：把股利换成企业可分派给股东的现金流，从而不依赖分派政策。
- 与 DDM 的关系：DDM 是 FCFE 在"长期稳定全额分派"假设下的特例。两者的隐含增长率之差，本身就是有信息量的指标（留存 vs 分派）。

## 3. 公式与口径（硬性）

```
正向:  P = FCFE1 / (r_e - g)
反向:  g_implied = r_e - FCFE1 / P

FCFE1 = 归母净利润 + 折旧摊销(D&A) - 资本开支(capex) - 营运资本增加(ΔNWC) + 净借款
        （1) 必须用**归母**净利润：FCFE 是普通股股东口径，不含少数股东
        （2) ΔNWC = NWC(期末) - NWC(上年同期期末)
             NWC = (流动资产合计 - 非经营性流动资产) - (流动负债合计 - 短期借款 - 一年内到期非流动负债)
             非经营性流动资产 = 货币资金 + 交易性金融资产 + 买入返售 + 拆出资金 + 衍生金融资产
        （3) 净借款 = 取得借款收到的现金 - 偿还债务支付的现金（现金流量表发生额，不用资产负债表差额）
```

**口径实测依据（为什么必须剔非经营性流动资产）**：贵州茅台 2026H1 拆出资金 1410.84 亿（集团财务公司吸存），
不剔除时 ΔNWC 从 32.26 亿虚增到 95.72 亿，FCFE 被压低约 63 亿。任何"集团内有金融子公司"的标的（茅台/五粮液/央企系）都会踩这个坑。

## 4. 取数实现与三个坑

- `app/tools/cash_flow_items.py`：D&A（折旧摊销）取数。**唯一可用源是东财现金流接口的补充资料段**
  （英文列名 `FA_IR_DEPR` / `IA_AMORTIZE` / `LPE_AMORTIZE` / `USERIGHT_ASSET_AMORTIZE`）。
  新浪现金流量表 71 列没有任何折旧摊销列；akshare 无巨潮现金流财报接口。
- `app/tools/fcfe_inputs.py`：五分量装配 + 每股 FCFE。

坑 1（期间）：**只有中报(6-30)和年报(12-31)有补充资料**，一季报/三季报该段全是 nan（澜起/茅台/湖南黄金实测）。
取数不能"拿最近一期"，必须回退到最近的有值期间，否则拿到一排空值。
坑 2（格式）：东财的 `REPORT_DATE` 是 datetime（`2026-06-30 00:00:00`），按 `20260630` 截前 8 位会整表跳过。
坑 3（缺项语义）：无融资动作的期间，`RECEIVE_LOAN_CASH` / `PAY_DEBT_CASH` 是 nan 而不是 0；
按"缺失即失败"处理会让 TTM 永远拼不出来，故对这两个科目按 0 计入并留痕；D&A/capex 则保持"全缺即失败"（不能假设为 0）。

期间口径：`ttm`（最近年报 + 最近半年报 − 上年同期半年报，缺一期回退 annual）/ `annual` / `h1`（半年口径会带 warning）。

## 5. 出口校验（valuation_guard R7）

```
折现率 - FCFE收益率 ≈ 隐含增长率      # 恒等式，窗口 200 字符，容差 0.15 个百分点(覆盖四舍五入)
```
触发门槛已放行"只有 FCFE 材料、没有 PE/EV 因子与目标价"的段落（否则整段被跳过，实测踩过）。

### 6.1 口径缺陷修正：交易性金融资产在东财有两个模板字段名（2026-09-13 亲踩）

`NONOP_CURRENT_ASSETS` 原来只列 `FVTPL_FINASSET`，但**一般企业模板**的流动资产里"交易性金融资产"落在
`TRADE_FINASSET_NOTFVTPL`（金融业模板才用 `FVTPL_FINASSET`）。实测 20 只样本：15 只走前者、1 只（招行）走后者、
4 只两边都是 0，**从未同时非零** ⇒ 两个字段名都列、直接求和不会双计。

后果（澜起 688008，2026H1）：交易性金融资产 29.17 亿（上年同期 6.67 亿），22.50 亿的**理财净买入被当成经营性营运资本占用**
→ TTM ΔNWC 虚增到 25.34 亿 → FCFE 被低估为 4.16 亿 / 0.3405 元 / 0.18%。修正后：

| 澜起 688008 TTM | 修正前(v4) | 修正后(v5) |
|---|---|---|
| ΔNWC | 25.34 亿 | **2.84 亿** |
| FCFE | 4.16 亿 | **26.66 亿** |
| 每股 FCFE（12.222 亿股） | 0.3405 元 | **2.1816 元** |
| FCFE 收益率（价 191.96） | 0.18% | **1.14%** |
| r=10% 隐含 g | 9.82% | **8.86%** |

同口径逐年（每股 FCFE）：2019 0.72 / 2020 0.54 / 2021 0.39 / 2022 0.76 / 2023 **0.15** / 2024 1.21 / 2025 1.09 / TTM 2.18 元
——即使口径修正后，FCFE 仍随营运资本大幅摆动，**不能拿单年折现**。

交叉验证（为什么 1.14% 可以信）：① 把 TTM 非经常性损益（8.21 亿，账面浮盈不产生现金）剔掉 → 18.45 亿 / 0.79%；
② 现金流量表口径 经营现金流 22.91 亿 − capex 4.09 亿 = 18.82 亿 / 0.80%。两条独立路径都落在 0.8% 附近。

`CACHE_SCHEMA` 已从 `v4` 升到 `v5`（改口径必须升，否则 6 小时缓存会把旧结果吐回来）。
自检 `scripts/verify_fcfe_inputs.py` 37 项：新增 A10b/A10c（两个模板字段名都要剔）、A19a-c（裸函数测摆动提示），
B7 从"澜起应出摆动提示"改为"ΔNWC < 5 亿（22.50 亿理财不计入）"回归锁 —— 原断言依赖未修正的错误口径，口径一修就假失败。


## 7. 残留与边界

- 股本口径：每股 FCFE 用行情口径总股本（总市值/最新价）优先，取不到退回资产负债表实收资本；
  两者差异 >2% 时告警并同时回传两个数（A+H 两地上市、刚完成增发的公司需人工判断）。
- FCFE 需要权益折现率 r_e，平台未内置 β/ERP 数据源 → 由报告按 CAPM 自述并进参数（同 DDM 的 r 处理方式）。
- 未做：正向 FCFE 目标价锚（刻意不做，避免与 DDM/倍数锚重复建设）；FCFF/WACC 口径未接。
