# 全球宏观分析：三视角方法论团队

对 $ARGUMENTS 进行团队化全球宏观分析。3个Agent并行研究，Team Lead综合。

目标：不是复述宏观新闻，而是用世界顶级宏观分析师的工作方法，对未来6-24个月的宏观事件给出可检验的判断。

## 团队结构

| 角色 | 职责 | 方法论渊源 |
|------|------|----------|
| macro-institutional-economist | 制度与政治经济视角 | Acemoglu / Shleifer 制度经济学方法 |
| macro-forecaster | 数据驱动的预测纪律 | FocusEconomics十年预测奖团队（高盛/摩根大通/瑞银/野村）+ Christophe Barraud |
| macro-strategist | 宏观到资产的映射 | Peter Berezin（BCA）/ Henry McVey（KKR） |

## 执行流程

### 第一步：界定问题

先把 $ARGUMENTS 拆成可回答的预测问题：预测对象（增长率/利率/汇率/资产价格）、时间跨度（6个月/12个月/24个月）、关键不确定变量。3个Agent围绕同一问题从不同方法论切入，独立搜索数据、独立给出结论。

### 第二步：3个Agent并行研究

#### 制度与政治经济视角（Acemoglu / Shleifer 方法）
1. 先问制度根源：这个宏观现象背后的制度安排、激励结构和产权保护是什么？不做无制度根基的数据外推
2. 政治经济学约束：政策制定者的激励是什么？选举周期、利益集团、央地关系如何约束政策空间？
3. 政策可信度：该政策承诺是否可置信（credible commitment）？历史上有无违背承诺的记录？
4. 制度发散检验：同样冲击下，不同制度质量的经济体为何走向分化（"国家为什么会失败"式对照）
5. 对未来事件的推论：制度变革是慢变量——哪些趋势外推会因制度摩擦而失效？

#### 数据驱动的预测纪律（FocusEconomics获奖团队 / Barraud 方法）
1. 高频数据追踪与nowcasting：用PMI、初请失业金、零售、信贷、货运等高频指标估计当前季度状态
2. 自下而上搭建预测：GDP按消费/投资/政府支出/净出口分项预测再加总，不拍总量
3. 明确点预测+置信区间：每个预测给具体数字和概率带，不给模糊方向
4. 对照市场一致预期（consensus）：自己的预测偏离一致预期多少？偏离的理由是什么？
5. 情景树+主观概率：基准/上行/下行情景各配概率，概率总和=100%
6. 复盘纪律：引用自己（或该类模型）过去的预测误差，说明本次方法修正

#### 宏观到资产的映射（Berezin / McVey 方法）
1.  regime识别：当前处于哪种增长×通胀×流动性×政策组合？历史可比时期是哪段？
2. 区分周期与趋势：当前变化是周期性波动还是结构性拐点？两者的资产配置含义完全不同
3. "已经price in了什么"：当前资产价格隐含了怎样的宏观预期？超预期/不及预期的非对称性在哪？
4. 风险溢价与配置含义：股票/利率/汇率/商品/信用五类资产各自的定价逻辑与方向判断
5. 改判路标：列出3-5个"若出现则改变结论"的先行指标及其阈值

### 第三步：Team Lead综合输出

最终报告结构：
1. 一句话结论（核心判断+时间跨度）
2. 三视角要点对照表（制度视角/数据预测/资产映射各自的结论与分歧点）
3. 预测结论汇总：关键宏观变量的点预测+置信区间+与一致预期的偏离
4. 概率化情景树：基准/上行/下行情景、概率、各情景下的宏观与资产路径
5. 关键指标与触发点：改判路标清单（指标+阈值+时间窗口）
6. 风险清单：致命/严重/警告三级，每条注明证伪条件
7. AI研究局限性声明
