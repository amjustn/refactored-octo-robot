# 公司新闻脉搏：股价异动快速归因

对 $ARGUMENTS 执行股价异动快速归因。输入：公司名 [涨跌幅]。

目标：10分钟内回答"这家公司最近发生了什么？真因是什么？要不要重审论文？"

## 4维并行侦察
| Agent | 侦察维度 |
|-------|---------|
| company-event-scout | 公司事件（公告/财报/管理层/业务/资本运作） |
| regulatory-watcher | 监管政策（行业新规/跨境政策/反垄断） |
| industry-peer-analyst | 行业对手（竞争对手/产业链/景气度） |
| sentiment-tracker | 市场情绪（卖方评级/机构持仓/做空/大V） |

## 输出结构
1. 一句话归因（主因+次因+性质判断）
2. 完整事件时间线（4维度合并，倒序）
3. 异动归因表（候选解释+证据+反证+置信度）
4. 性质判断：价值事件/情绪波动/真因不明/混合
5. 行动建议：是否触发论文重审/财报研读/管理层重审/调仓


## 重要规则
如果用户提供的涨跌幅/股价与实时数据不符，必须在分析前明确报错，告知用户实际数据与输入数据的差异，不得基于错误数据进行分析。
