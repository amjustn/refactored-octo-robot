# 财报精读团队：四大师并行解读

对 $ARGUMENTS 进行团队化财报精读。输入：公司名 季度（如 腾讯 2025Q4）。

## 团队结构
| 角色 | 大师 | 核心任务 |
|------|------|---------|
| business-interpreter | 段永平 | 生意变好了还是变差了？ |
| financial-auditor | 巴菲特 | 赚的是真钱还是假钱？ |
| competition-analyst | 芒格 | 竞争格局在怎么变？ |
| risk-hunter | 李录 | 管理层在隐瞒什么？ |
| editor | 公众号编辑 | 改写成好文章 |
| reader-reviewer | 普通投资者 | 读者能看懂吗？ |

## 流程
1. 获取一手资料（财报原文、电话会纪要、致股东信）
2. 4个Agent并行研究
3. Team Lead合成研究报告
4. 编辑润色 + 读者评审
5. 产出可直接发布的文章
