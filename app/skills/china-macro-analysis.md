# 中国宏观分析：四视角方法论团队

对 $ARGUMENTS 进行团队化中国宏观分析。4个Agent并行研究，Team Lead综合。

目标：以中国顶级宏观分析师的工作方法，回答"政策会怎么做、经济往哪走、资产怎么定价"，对未来6-24个月给出可检验的判断。

## 团队结构

| 角色 | 职责 | 方法论渊源 |
|------|------|----------|
| cn-policy-framework | 政策反应函数与货币金融框架 | 彭文生 / 黄益平 / 伍戈 / 邢自强 |

## 执行流程

### 第一步：界定问题

先把 $ARGUMENTS 拆成可回答的问题：政策维度（货币/财政/地产/监管）、周期维度（当前处于信用周期与库存周期哪一段）、时间跨度（6个月/12个月/24个月）。4个Agent围绕同一问题从不同方法论切入，独立搜索数据、独立给出结论。

### 第二步：4个Agent并行研究

#### 政策反应函数与货币金融框架（彭文生/黄益平/伍戈/邢自强 方法）
1. 把政治局会议、中央经济工作会议、货币政策执行报告当作"政策反应函数"来读：什么数据触发什么政策，而不是逐字解读通稿
2. 区分宽货币与宽信用：降准降息只是宽货币，信用是否扩张要看社融/信贷/M1的传导是否通畅
3. 金融周期视角（彭文生）：信用创造与地产作为抵押品的顺周期放大机制，判断当前处于金融周期上半场还是下半场
4. 政策put/call逻辑：通缩压力、名义GDP增速、就业数据到什么阈值会触发加码宽松？什么信号会触发边际收紧？
5. 政策可信度与约束：汇率、银行净息差、资金空转对宽松空间的约束

#### 高频数据与周期跟踪（陆挺/郭磊/陶川·李超/高善文 方法）
1. 搭建高频证据链：PMI分项（新订单/出口订单/产成品库存）、高频开工率、30城地产成交、票据利率、出口集装箱运价、挖机销量等交叉印证
2. 区分信号与季节性噪音：所有高频数据先剔除春节错位等季节因素再下结论
3. 官方数据与微观证据交叉验证：统计数据与市场微观证据冲突时，以证据链完整性定取舍（高善文的微观证据链方法）
4. 周期定位：库存周期（主动补库/被动补库/主动去库/被动去库）、产能周期位置、地产周期阶段
5. 事件解读纪律：政策会议与突发事件只评估其对证据链的增量信息，不追热点

#### 汇率、跨境资本与国际收支（管涛/张明/张斌 方法）
1. 国际收支表拆解：经常账户（货物贸易顺差趋势）与资本金融账户各自的驱动力
2. 人民币汇率三因素：中美利差、结售汇行为（企业结汇率/售汇率）、预期管理（中间价/离岸流动性）
3. 资本流动压力评估：用银行代客结售汇、涉外收付款、外汇储备变动、CNH-CNY价差衡量压力方向与量级
4. 政策工具箱推演：逆周期因子、外汇准备金率、远期售汇风险准备金、口头干预各自的启用条件与历史效果
5. 外部平衡：出口竞争力与汇率错配的量化判断，极端情景（关税升级/美元流动性冲击）推演

#### 中长期结构与增长趋势（李迅雷/徐高/樊纲/殷剑峰/苗建军 方法）
1. 潜在增长分解：劳动力、资本、全要素生产率各自的贡献趋势，未来5-10年潜在增速区间
2. 债务可持续性算术：宏观杠杆率×名义增速×利率的动态演化（r-g框架），各部门（政府/企业/居民）加杠杆空间
3. 区分结构性与周期性：当前增长放缓中多少是趋势下行、多少是周期拖累，两者的政策含义完全不同
4. 拖累量化：人口老龄化、地产长周期见顶对潜在增速的定量拖累（每年多少个百分点）
5. 总量与分化（李迅雷）：总量指标掩盖的分化——区域、行业、收入分层，寻找结构性亮点
6. 逻辑闭环检验（徐高）：债务与需求的传导链条是否闭合，任何结构判断必须能讲通微观机制

### 第三步：Team Lead综合输出

最终报告结构：
1. 一句话结论（核心判断+时间跨度）
2. 四视角要点对照表（政策/数据/汇率/结构各自的结论与分歧点）
3. 预测结论汇总：关键变量（GDP/CPI/社融/汇率/政策利率）的预测+与一致预期的偏离
4. 概率化情景树：基准/上行/下行情景、概率、各情景下的政策响应与资产路径
5. 关键指标与触发点：政策加码/转向的触发阈值清单（指标+阈值+时间窗口）
6. 风险清单：致命/严重/警告三级，每条注明证伪条件
7. AI研究局限性声明
