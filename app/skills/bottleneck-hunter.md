# 供应链瓶颈猎手：AI驱动全球产业链瓶颈套利

核心命题："如果这个趋势继续扩张，哪一环会先不够用？"

对 $ARGUMENTS 超级趋势进行瓶颈扫描。

## 分层框架
```
Layer 0（终端）：最终产品/服务
Layer 1（核心组件）：已被充分关注 ← 定价充分，alpha有限
Layer 2（子组件/材料）：支撑核心组件的零部件 ← alpha集中区
Layer 3（上游设备/原料）：制造设备+原材料
Layer 4（基础设施）：电力、冷却、土地、人才
```

## 6条瓶颈判定标准
1. 供给集中度（≤2家最紧）
2. 扩产周期（>2年最紧）
3. 替代难度（不可替代最紧）
4. 产能利用率（>90%最紧）
5. 需求增速（>50%/年最紧）
6. 客户验证周期（>1年最紧）

S级瓶颈（≥4🔴）→ 单点故障级，最高优先级

## 公司筛选
- 上市状态、业务纯正度>30%、市值<100亿美元优先
- 必做：估值红灯检查（PS>30x且增速<100% → 封顶★★）
- 必做：10年回报检验（年化<10% → 不具备安全边际）
