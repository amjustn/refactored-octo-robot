# 巴菲特价值投资买入前 Checklist

对 $ARGUMENTS 执行巴菲特价值投资买入前 Checklist 分析。

支持输入格式：单个或多个公司，用逗号/顿号/空格分隔。

## 六关快速筛选

### 第一关：能力圈
- 能用一句话说清楚公司靠什么赚钱吗？
- 10年后大概率还在做什么生意？
- 哪些关键变量决定成败？

### 第二关：好生意（经济特征）
| 指标 | 参考标准 |
|------|---------|
| ROE（5年均值） | >15%优秀, >20%卓越 |
| 毛利率 | >40%暗示定价权 |
| 自由现金流 | 持续为正、≈净利润 |
| 资本开支强度 | 轻资产优于重资产 |
| 负债水平 | 有息负债/净利润<3年 |

### 第三关：护城河
| 类型 | 检查 |
|------|------|
| 品牌/定价权 | |
| 转换成本 | |
| 网络效应 | |
| 成本/规模优势 | |
| 技术/专利壁垒 | |

追加检验：给竞争对手100亿，能否复制这门生意？

### 第四关：管理层
- 诚实度（承诺vs交付）
- 资本配置能力（回购/分红/并购记录）
- 股东利益导向（持股、薪酬）
- 所有者心态（创始人 vs 职业经理人）

### 第五关：安全边际
- 当前PE/PS/PB vs 历史分位 vs 同业
- 三情景估值（乐观/中性/悲观）
- 如果判断有误最多亏多少？
- 股价腰斩你敢加仓吗？

### 第六关：决策纪律
- 是否因为FOMO想买？
- 是否因为别人推荐才想买？
- 如果停牌5年你能接受吗？
- 买入论述能否用200字以内写清楚？

## 镜子测试

5句话说清楚为什么买。5句话说不完整 = 不买，没有例外。

## 快速否决清单（8条红线）
1. 说不清楚怎么赚钱
2. 连续3年FCF为负
3. 管理层诚信污点
4. 竞争优势被不可逆侵蚀
5. 需要博傻
6. 无法承受归零
7. 买入理由主要是"别人都在买"
8. 无法用200字写清楚买入理由
